# leetcode-solutions
Data structures and algorithms practice, primarily written in C++.

## Commit Conventions

This repository follows [Conventional Commits](https://www.conventionalcommits.org/).

| Type | Description |
|---|---|
| `feat:` | New solutions |
| `fix:` | Bug fixes |
| `perf:` | Performance optimizations |
| `refactor:` | Code restructuring |
| `docs:` | Documentation updates |

Examples:
- `feat: solve 0020 Valid Parentheses`
- `perf: optimize 0004 median search`
- `docs: add review tracker`
